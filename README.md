# Products Fetch App

A small frontend project that retrieves product data from the DummyJSON API and renders product cards dynamically in the page.

## Features

- Fetch product data from an external REST API
- Handle the response with JavaScript Promises
- Render product cards dynamically using DOM manipulation
- Display product images, titles, descriptions, and prices
- Use Bootstrap for the page layout and card styling

## Tech Stack

- HTML5
- JavaScript
- Fetch API
- Promises
- DOM Manipulation
- Bootstrap 5
- DummyJSON API

## Run Locally

```bash
git clone https://github.com/aya-aboelkheir/DOM_project.git
cd DOM_project
```

Open `index.html` in your browser. An internet connection is required to load Bootstrap and product data from DummyJSON.
